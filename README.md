# Customer Segmentation using K-Means

## 📌 Project Overview

This project performs customer segmentation using the **K-Means clustering algorithm**.

The goal is to group customers based on their **Annual Income** and **Spending Score** so that businesses can better understand customer behavior and create targeted marketing strategies.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- K-Means Clustering
- Hierarchical Clustering
- PCA

## 📊 Project Features

- Data loading and preprocessing
- Missing value checking
- Exploratory data analysis
- Elbow Method to determine the optimal number of clusters
- Customer segmentation using K-Means
- Silhouette Score evaluation
- Hierarchical Clustering with Dendrogram
- PCA-based cluster visualization
- Clustered dataset exported as CSV

## 📈 Results

The K-Means model successfully divided customers into **5 clusters** based on their income and spending behavior.

The project achieved a **Silhouette Score of approximately 0.55**, indicating reasonably well-separated customer groups.

## 📁 Files

- `customer_segmentation.py` – Main Python implementation
- `customer_segments.csv` – Final clustered customer dataset

## 🎯 Applications

Customer segmentation can be used for:

- Targeted marketing
- Personalized offers
- Customer behavior analysis
- Business decision-making
- Identifying high-value customers
